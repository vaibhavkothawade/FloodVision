# FloodVision

FloodVision is an AI-powered flood monitoring and impact assessment platform that leverages satellite imagery, U-Net segmentation, GIS analytics, and Large Language Models (LLMs) to detect flooded regions, assess infrastructure risk, and generate actionable disaster response insights through an interactive dashboard.
